SHUBH TOUR & TRAVELS — PWA BUILD

1. Upload ALL files to the same GitHub Pages repository root.
2. GitHub Settings > Pages > Deploy from branch > main > /(root).
3. Open the HTTPS GitHub Pages URL in Chrome on Android.
4. Tap INSTALL APP when it appears, or Chrome menu > Add to Home screen.
5. From then on, open Shubh Tour from the phone home screen with one tap.

Important: this version stores operational data in the browser. PWA/service-worker caching prevents the app shell from disappearing/offline-breaking, but it is NOT a cloud backup. Browser data can still be lost if site data is cleared. For multi-device/cloud-safe storage, a backend database is needed.
